# Carrel 0.4: machine, connection and publication intent

The member path now describes machines, allowed connections and public endpoints in one existing
`deployment_plan` / `deployment_apply` specification. It returns one durable operation, SSH commands
and endpoints. It requires no physical host, bridge, VLAN, gateway or proxy selection. Member tool
count remains 40; no new scheduler, queue service, database or workflow language was introduced.

The current core acceptance is deliberately limited to provisioning and SSH, publishing an existing
application, and an app/database pair with an enforced connection rule. ISO/image import, full skill
and issue catalogs, special ingress requests, alumni scheduling, legacy migration and multiple nodes
remain roadmap work. Existing experiment network tools remain available when topology is the task.

## Contract and reliability changes

- `connections` grants an exact source machine, protocol and destination port. Its destination must
  explicitly use `network_access=restricted`. The compatible `tenant` default still allows all
  same-tenant primary traffic. Restricted guests cannot attach unfiltered experiment NICs.
- `publications` supports HTTPS and assigned TCP/UDP ports, including existing machines. Planning
  checks aggregate quota; application reserves all new machines and grants before provisioning.
  Retry checks original allocation identities; rollback preserves reused machines, grants and routes.
- DNS-provider calls are removed from core node/edge reconciliation. Domain maintenance records
  failures per tenant, so one DNS failure does not prevent another tenant's network convergence.
- Certificate-budget exhaustion produces a durable `waiting` operation with `ready_at`, releases the
  writer and automatically resumes, including after restart. A domain becomes `ready` after DNS,
  certificate and route application; adapter failures retain a recoverable `configuring` state.
- Temporary quota expiry restores the previous limit and exposes `over_limit`. It blocks further
  growth in that dimension, preserving machines and allowing reductions/cleanup.
- Existing tenant queries no longer depend on registering unrelated project tenants. `whoami`
  reports individual onboarding failures without hiding usable tenants.
- Suspension immediately persists `suspending`, blocks new mutations and takes priority over queued
  ordinary work. Provisioning/readiness checks observe suspension at safe checkpoints. Admission is
  bounded to 256 pending operations overall and 16 per tenant; idempotent resubmission and suspension
  remain available when full.

## Local validation

114 tests pass on Python 3.13. Ruff lint/format, script compilation and whitespace checks pass.
Regression tests exercise all five reliability cases above, certificate-budget waiting/restart,
whole-group reservation rollback, reuse of machine/domain identifiers, ready-state accuracy,
partial cleanup with quota retention, preservation of existing routes and TCP/UDP coexistence.
The rendered node firewall is also checked for exact source/protocol/port enforcement and rejection
of an unfiltered NIC bypass. Fault injection uses an in-memory database and fake adapters.

## Verification boundaries

`verification: routing_configured` describes publication configuration. It does not claim the
application returned a successful response; a client must test the application separately. VM
readiness checks still distinguish SSH, cloud-init and requested guest-local application checks.

The implementation retains one infrastructure writer. Certificate-budget waiting releases it;
actual certificate issuance and periodic DNS maintenance still occupy it. Suspension does not
interrupt a command already submitted to the hypervisor. Default tenant networking is compatible,
not restricted by default. This is a single-node acceptance, not a multi-node or independent security
auditing claim. No new native-agent benchmark, production fault injection, full disaster restore,
telemetry freshness acceptance or email notification test is claimed here.
